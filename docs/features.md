## Product boundary

This release retools the **desktop browser / installed PWA workspace**, published
to GitHub Pages at <https://actofrod.github.io/Kiln/> on every merge to `main`.
Because it is a web app, there is no separate Windows executable; Chrome / Edge
can install the site as a desktop app. It is not a native audio driver or full
Live / Logic parity. Desktop layout and editing take priority; mobile-specific
PWA interaction design is intentionally deferred. Existing PWA infrastructure
and browser-local songs remain compatible.

The track model deliberately combines an Ableton-style shared session and
arrangement engine with a Logic-like horizontal region timeline and inspector.
It does not copy either application's assets, devices, project formats or UI.

Audio regions now reference immutable per-clip assets, so different files can
share a track. The next foundational work is automation, then comping, routing
and pitch-preserving warp. A native shell alone
would not provide a native low-latency audio engine or plug-in host.
